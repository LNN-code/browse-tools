# Search Detail Auto Browser

一个 Chromium/Edge/Chrome 可加载的本地扩展，用于在搜索列表页按顺序点击列表项，打开或切换详情内容，提取岗位信息后继续浏览下一条。默认浏览 10 条，浏览数量可在独立设置页修改。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`d:\browse\tools2`。

## 使用

1. 打开目标搜索列表页。
2. 点击浏览器工具栏里的“自动浏览搜索详情”扩展图标。
3. 点击弹窗右上角“设置”，打开独立设置页。
4. 在设置页选择“BOSS 直聘”“智联招聘”或“通用站点”，插件会按站点分别保存配置。
5. 在“左侧列表项 CSS 选择器”里填写或微调列表中职位卡片或详情入口的选择器。
   - 默认值是 `a[href]`，适合列表项本身就是链接的页面。
   - BOSS 直聘这类左侧列表页面通常可用 `.job-card-wrapper, .job-card-box`。
   - 智联招聘可先尝试 `.joblist-box__item, .joblist-box__iteminfo, .job-item, a[href*='jobs.zhaopin.com'], a[href*='/jobdetail/']`。
   - 如果页面结果卡片有固定类名，例如 `.result-card` 或 `.result-card a.title`，建议填更精确的选择器。
6. 如果详情在右侧面板里展示，可以在“详情区域 CSS 选择器”里填右侧面板选择器。
   - BOSS 直聘可先尝试 `.job-detail-container, .job-detail-box, .job-detail`。
   - 智联招聘可先尝试 `.job-detail, .job-detail-container, .job-detail__container, .position-detail, .job-intro, .detail-container, .summary-plane, .describtion, .description`。
   - 留空时扩展会自动寻找右侧详情区域。
7. 设置浏览条数、起始序号、等待配置和“下一条模式”，然后点击“保存设置”。
8. 回到扩展弹窗，点击“开始”。

扩展会在页面右下角显示当前进度。对于 BOSS 直聘这类“左侧列表 + 右侧详情”的页面，扩展会点击左侧职位卡片，提取当前详情区域里的岗位信息，然后直接点击下一条。

对于智联招聘这类“列表页点开详情新标签页”的页面，扩展会从列表页打开详情新标签，提取并保存岗位信息后自动关闭当前详情标签，再切回原列表页继续下一条。

每次打开或切换到一个详情后，扩展会提取岗位信息并保存为 Markdown 文件，不再进行下拉/下滑。BOSS 直聘文件会下载到浏览器默认下载目录下的 `boss-jobs/` 文件夹，智联招聘文件会下载到 `zhaopin-jobs/` 文件夹，其他网站会下载到 `job-details/` 文件夹。文件名格式为：

```text
岗位名称-企业名称-薪资区间.md
```

BOSS 直聘初始 HTML 通常只有 `#app` 和加载脚本，职位列表由 Vue 动态渲染。扩展会等待列表项出现后再开始点击，默认最多等待 20 秒。

扩展会按站点保存配置。BOSS 直聘和智联招聘的选择器、浏览条数、等待参数会分别保存，下次打开对应站点时自动带出，不会互相覆盖。

当前页面可识别的列表项浏览完后，会提示你手动跳转到下一页；跳转完成后，扩展会继续执行剩余条数。如果目标网站翻页后网址没有变化，手动翻页完成后点击右下角浮层里的“继续”按钮即可从当前页面第 1 条继续。

在设置页里还可以：

- 将“下一条模式”切换为“自动下一条”或“手动下一条”。手动下一条会在每条详情处理完后停住，等你在弹窗里点“下一条”再继续。
- 关闭“保存到本地”，只提取详情内容，不触发 Markdown 下载，但仍保留岗位上下文供评分使用。
- 调整设置后点击“保存设置”，如果是从弹窗打开的设置页，会尝试同步到当前正在运行的页面。

在弹窗里可以直接点击“下一条”，手动推进到当前页的下一条岗位。

## 简历匹配评分

1. 在设置页粘贴简历 Markdown / 文本，或上传 `.pdf` / `.md` / `.txt` 文件。
2. 在设置页填入 DeepSeek API Key 并保存。
3. 在弹窗里点击“评分当前岗位”，可以对当前岗位详情页或刚浏览完的岗位上下文评分。
4. 扩展会把岗位信息和简历一起发给 DeepSeek，返回 0-100 的匹配评分和结论。

勾选“达标自动沟通”后，自动浏览每条岗位时会先提取岗位详情并评分；当分数大于等于“匹配阈值”时，扩展会点击页面上的“立即沟通”。如果出现“已向BOSS发送消息”弹窗，会自动点击“留在此页”，然后继续处理下一条岗位。

## 注意

- 扩展不能在 `chrome://`、`edge://` 等浏览器内部页面运行。
- 扩展依赖页面 DOM 和 CSS 选择器，不同网站需要填写不同的“左侧列表项 CSS 选择器”。
- 某些网站会拦截脚本触发的点击，遇到这种情况请把选择器设置为真实可点击的卡片或链接元素。
- 请遵守目标网站的使用条款和访问频率要求。
